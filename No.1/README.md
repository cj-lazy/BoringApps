# No.1 本地笔记 · 4.4.0

基于 Tauri、React 和 BlockNote 的本地技术笔记工具。支持 Markdown、公式、代码、流程图、图片与文件附件、双栏编辑，以及 Word/PDF 和笔记附件包导出。

## 4.4 工作流改进

- 全局替换默认只处理正文，单独选择是否修改笔记属性、链接目标、代码和公式。可预览全库变化、勾选笔记后一次提交；写入前核对每篇原文，保留历史版本并在冲突时取消整批操作。
- 工具栏“命令”或 Ctrl+Shift+P 打开命令面板。更多菜单中的“快捷键与工具栏”可改组合键、清除绑定、选择常用按钮，并检查冲突。撤销、复制粘贴及系统关闭键保留；全局快速记录仍为 Ctrl+Alt+N。
- “Word 排版模板”提供标准笔记、学术报告、紧凑讲义，可调整 A4/Letter、字体、字号、行距和页边距，启用标题编号、图片/流程图题注、独立公式编号、页眉与页码。设置保存在当前笔记库；字体由打开文档的电脑提供，编号域可在 Word 中更新。
- 嵌套列表、多段列表和多段引用可直接编辑。脚注有可编辑的正文和标识，双向保存为 Markdown，导出为原生 Word 脚注。复杂提示框、HTML 等尚不能完整表达的结构继续保留原文。
- “任务汇总”或 Ctrl+Shift+T 汇总全库 Markdown 待办，按文字、来源笔记、标签和完成状态筛选。勾选更新原笔记，点击任务文字跳转到来源。阅读模式下不能勾选。
- “插入段落引用”选择来源段落或章节，在当前块之后插入实时内容或跳转链接。来源写入 `<!-- no1:anchor:ref-… -->` 稳定标记，引用使用 `![[笔记#^标记|标题]]`；改标题后继续有效，程序内移动笔记会维护目标路径。不要删除定位标记。实时内容只读，保存来源或重新聚焦窗口后更新；嵌套引用不递归展开，防止循环。

## 使用与更新

本地整理后的便携程序位于 `release/portable-note.exe`，源码构建的程序位于 `src-tauri/target/release/portable-note.exe`。

默认笔记库位于程序旁边的 `data` 文件夹，可通过侧边栏“笔记库与备份”打开其他已有或空文件夹。同一笔记库同时只允许一个 No.1 程序写入。更新时先退出旧程序，备份笔记库，再替换程序；如使用自选库，同时保留程序旁的 `.no1-libraries.json`。

- 左侧选择笔记；双栏时 `Ctrl+点击` 在右栏打开。
- 输入 `/` 插入内容，两栏使用相同的插入菜单。
- 默认停止输入 5 秒后自动保存，可在设置中改成 15/30/60 秒或仅手动保存。`Ctrl+S` 保存两栏；切换、关闭、失焦时也会保存。
- 编辑停止约 700 毫秒后写入恢复草稿。异常退出后重新启动可选择恢复；草稿恢复和正式保存是两个步骤。
- 搜索、撤销、字数、大纲、源码和导出跟随当前活动栏。
- 工具栏“更多”中提供源码切换、历史版本、草稿恢复、附件链接检查和附件包导出。
- 设置中可调整正文宽度、字号、行距和背景。

## 4.3 的使用体验与整理改进

- **界面与编辑**：在设置中选择浅色、深色或跟随系统。标题旁的箭头可折叠章节，折叠不改写 Markdown；打印仍输出完整正文。粘贴纯文本 TSV 表格会生成结构化表格，保留空单元格、带引号的换行和双引号；已有 HTML 表格沿用编辑器的格式粘贴。
- **性能**：第二个编辑器在真正使用右栏时创建；文件树按可见行显示，支持 Home/End/PageUp/PageDown。链接悬停预览短时间复用索引，笔记变更后更新缓存。桌面验收保存启动时间、输入回显往返耗时、可见行数和 JS 堆占用，便于后续比较。
- **批量整理**：智能集合支持多选笔记，批量调整类型、状态及标签，支持标签重命名和合并。表格中的类型、状态、标签可直接编辑，离开单元格或 Enter 保存。可按标题、日期、类型、状态排序、分组，并固定集合到侧边栏。
- **快速记录**：点击“快速记录”或使用 `Ctrl+Shift+N`；Windows 全局快捷键为 `Ctrl+Alt+N`（若已被其他程序占用，可使用应用内入口）。独立小窗口可保存到收件箱或追加到今日笔记，附带时间和可选来源链接，未保存输入保留在本机。`Ctrl+Alt+D` 打开今日笔记。
- **附件**：“更多 → 批量导入附件”或拖入多个文件，导入队列显示进度并可取消；同一内容复用已有附件。附件管理展示引用、重复内容和缺失链接，可选替代文件批量修复。资料包通过后台分块压缩导出，取消时保留原有目标文件。

本轮未加入定期备份或版本更新功能，也未扩展 PDF 精读。原有手动备份与恢复继续使用。

## 4.2 的五项改进

1. **快速搜索与导航**：`Ctrl+P` 查找标题、正文和标签；按目录、日期、类型、状态筛选。标题优先，空查询优先最近访问；方向键和 Enter 可操作。工具栏前进/后退支持 `Alt+Left/Right`。原全局搜索替换继续保留，搜索索引按文件变化增量更新，可手动刷新。
2. **自动保存与笔记库管理**：保存有历史版本；外部修改按 3 秒轮询和窗口重新激活检查，干净文档自动刷新，有未保存修改时比较处理。文件被移走后可将窗口内容另存。笔记库可切换，完整备份包含附件、历史、草稿、模板和设置；恢复前校验每个文件，生成独立新目录。
3. **属性与智能集合**：“更多 → 笔记属性与标签”编辑标题、标签、类型、状态、来源和日期。属性保存在 Markdown 顶部 YAML 中，保留未编辑的自定义字段和注释。在“智能集合”保存筛选条件，支持列表和表格浏览。
4. **笔记关联**：输入 `[[` 联想笔记，输入 `#` 继续查标题；也可使用“更多 → 插入笔记链接”。支持反向引用列表、标题定位、悬停预览和标准 Markdown 相对链接。移动、改名会维护有效的引用，并保留代码、公式中的字面文本；中断操作有恢复日志。
5. **模板与片段**：侧边栏“模板与片段”提供论文精读、实验记录、会议纪要、周报和检查清单。支持保存整页或选中块，修改后另存自定义模板。变量 `{{title}}`、`{{date}}`、`{{datetime}}` 在使用时替换。整块片段插入在打开窗口前的光标块之后，已有属性不会作为第二份属性区插入正文。

PDF 精读、OCR 和批注未在本次扩展。原 PDF 预览与打印导出继续保留。

## 数据与便携

- `.md`：笔记正文；`assets`：附件。
- `.workspace.json`：收藏、标签页、滚动位置、布局、阅读设置、自动保存间隔、最近访问和智能集合。
- `.templates.json`：自定义模板与内容片段；内置模板随程序提供。
- `.uploads`：尚未完成的附件导入临时区，不放入完整备份。
- `assets/shared`：按内容校验值保存的新附件；附件显示名仍保留在笔记中。
- `.no1.lock`：运行中的笔记库占用锁，备份时跳过。
- `.drafts`：按编辑会话隔离的恢复草稿；未恢复的旧草稿不会被当前会话的保存清除。
- `.backups`：正式保存前的历史版本；可在界面中对比并恢复。
- `.history-renames.json`：笔记和文件夹改名后的历史路径关联。
- `.trash`：回收站。

附件路径以笔记库根目录为基准，显示时解析到当前机器。旧的 `data/assets` 绝对链接仍可兼容读取；通过“检查附件链接”预览缺失附件和迁移候选，再选择需要迁移的笔记。迁移会先备份，不会仅因打开笔记就改写原文。

“导出笔记及附件包”生成 ZIP，将 Markdown 放在包的根目录，并带上所有引用的本地附件。完整解压后可在其他 Markdown 工具中打开。远程链接保持原样，附件包不下载远程资源。

外部程序同时修改文件时，程序取消覆盖，并提供磁盘版本与当前内容的对比，可采用磁盘版本或将当前内容另存为副本。

## 开发与验证

```powershell
npm ci
npm run tauri dev
npm test
npx tsc --noEmit
npm run tauri build -- --no-bundle
```

Rust 检查、真实 Markdown 样本验证和隔离桌面验收步骤见 `tests/README.md`。详细改动与验证记录见 `OPTIMIZATION-NOTES.md`。

完整备份是带 `.no1-backup.json` 校验清单的独立文件夹，不会覆盖现有库。应将备份存放在当前笔记库之外；通过“选择并检查备份”核对后恢复到新文件夹。程序旁 `.no1-libraries.json` 只记录本机库位置，不属于可移植笔记内容。
