# Markdown 与保存兼容性

本文件记录 4.1.0 继续保留的底层保证；本轮产品改动见 [OPTIMIZATION-NOTES.md](OPTIMIZATION-NOTES.md)。

## 原文保真

Markdown 先按语法树分组，再安装到块编辑器。保存时复用未修改分组的原文，保留 BOM、换行、缩进、较长代码围栏、表格对齐和原有空白。无法可靠可视化编辑的脚注、前置信息、HTML 和复杂嵌套结构保留为可编辑原文块，不执行 HTML。

新建笔记在磁盘上是真正的空文件。仅打开、阅读、搜索和切换未编辑笔记，不会触发重新转换并写回。修改后的可视化块使用对应的 Markdown 序列化规则，不承诺将所有 Markdown 扩展都转换成可视化块。

## 数学公式

支持独立与行内的美元定界符，以及 `\[...\]` 和 `\(...\)`；识别发生在 Markdown 转义前。普通金额、显式转义、代码、HTML 和链接地址不会自动当作公式。

旧版导出器曾把 `@@LATEX_ID_*@@` 占位符和硬换行混入大公式。专用兼容预览仅识别这种格式并拆分显示，不猜测缺失下标、不把星号改成下划线，也不补造数学符号。原文仍可查看和编辑；未明确编辑时不自动迁移。阅读模式下原文只读。

正起始编号列表可在独立公式之后继续编号；零起始列表保留为原文，避免被编辑器静默改成 1。

## 保存与恢复

保存、切换、重命名、移动和删除按队列顺序处理。保存失败时保留当前编辑内容，并中止后续切换或关闭。同一笔记不能在左右两栏重复编辑；切换笔记不会进入撤销历史。

后端在写入前核对磁盘原文，通过同目录临时文件替换，并先备份旧内容。无法备份或发现外部修改时取消覆盖。备份保存在 `data/.backups`，可在“更多 → 历史版本”中对比和恢复。

恢复草稿保存在 `data/.drafts`，按编辑会话隔离。新一轮编辑和正常保存不会清除尚未处理的旧草稿。

## 附件与边界

路径、目录范围、Windows 设备名和上传文件名都经过校验；本地资源读取限制在当前笔记库的 `assets` 目录。移除附件引用不会立即删除附件，以保留撤销、共享引用、回收站和历史版本的恢复能力。

容量管理保留最新版本和近期备份，并检查当前笔记、备份、草稿、回收站中的附件引用。候选过期或内容变化时拒绝执行清理，需要在界面中明确选择后才永久删除。

## 导出与验证

Word 使用原生段落、表格、列表和可编辑 Office Math，不用公式图片或 Markdown 源码代替公式。不支持的复杂公式会中止导出。普通图片和 Mermaid 图表仍以图片嵌入；需要携带附件时可导出 ZIP。

正式版启用内容安全策略，Mermaid 使用严格模式，附件预览的读取与渲染任务支持取消。验证步骤和公开合成样本见 [tests/README.md](tests/README.md)；本机产生的验收资料保留在被忽略的 `artifacts` 目录。
