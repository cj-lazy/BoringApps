# 4.1.0 优化记录

日期：2026-11-01。

## 已完成

1. **Callout 内容完整性**：正文绑定 BlockNote 的内容区域，标题可编辑，阅读模式下禁止修改。采用 `> [!INFO/WARNING/ERROR/TIP]` 保存，保留正文、行内格式和公式。无法表示成行内内容的复杂提示框继续保留原文，避免丢失嵌套内容。已丢失的历史正文无法根据界面文字自动补回。
2. **附件便携性**：新写入的附件链接使用相对笔记库的路径；显示时映射当前目录，兼容旧的绝对链接。新增链接检查、缺失提示、选择迁移和包含附件的 ZIP 导出。迁移只改真实 Markdown 链接目标，不改代码中的相似字符串。
3. **恢复流程**：空闲后自动写入草稿，按会话隔离，保留尚未恢复的旧内容；启动时提供恢复选择。新增历史版本列表、差异预览和恢复，改名或移动后仍能追踪历史。外部冲突可以采用磁盘版本并保留恢复草稿，或将编辑内容另存为副本。
4. **搜索闭环**：全局搜索分页展示，准确提示还有更多结果；点击结果定位对应内容并高亮。替换先展示差异和数量，默认排除代码、HTML、公式和链接地址，也可手动包含。保存时再次检查磁盘原文。
5. **双栏一致性**：两栏共用编辑器、源码模式和插入菜单；搜索、撤销/重做、字数、大纲和导出跟随活动栏。禁止同一笔记在两栏重复编辑。
6. **阅读与界面**：正文最大宽度、字号、行距可调整；统一导航图标和工具栏；小窗口收起次要导出按钮，大纲改为覆盖面板。新增完整 Markdown 源码编辑。收藏、标签页、滚动位置、布局和阅读设置保存在笔记库中。文件树支持方向键和 Enter。
7. **结构与性能**：拆出文件树、工具栏、编辑器、搜索、恢复、历史和设置组件，以及导出服务、草稿保护、附件路径、差异和替换工具；后端拆出笔记库与分页搜索模块。脏状态按变更块更新，文件树避免跟随正文输入重复渲染。附件预览按可视区域和展开状态加载，最多同时解析两份，文本预览限制读取量。搜索高亮不修改编辑器管理的 DOM。打印前准备附件预览。

## 兼容边界

- 未修改的旧 Markdown 继续保留原文；附件迁移需要在界面中明确选择。
- 相对附件路径以库根目录为基准；导出 ZIP 会把笔记放到根目录，以便独立使用。
- Word 保持原生 Office Math；不支持的复杂公式仍会明确中止导出。Word 附件为链接，需要一起携带附件时使用 ZIP。
- PDF 继续使用系统打印。自动验收验证 WebView 的打印输出，不包含所有物理打印机驱动的系统界面。
- 文本附件最多预览约 64 KB，Word 大附件可直接用系统程序打开；原文件不截断。
- 编辑器和 Mermaid 仍存在较大的构建分块，构建警告保留，没有用提高阈值隐藏。
