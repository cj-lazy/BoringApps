# 4.4.0 编辑与知识工作流优化

日期：2026-11-02。

本轮实现六项：替换保护与全库预览、命令和快捷键定制、Word 排版模板、复杂列表/引用/脚注编辑、跨笔记任务汇总、带稳定定位的实时段落引用。继续沿用 Markdown、草稿恢复、历史版本、预期原文冲突检查和批量事务；未扩展 PDF 精读、OCR、定时备份或程序更新。

- 替换解析 Markdown 语法区间，分别保护 YAML/TOML、链接目标（含双链和实时引用）、数学和代码；显示文字和别名单独替换。全库替换用已有批量事务，核对全部原文后写入并保留备份。
- 快捷键配置和工具栏按钮写入工作区，录入时检查组合键、冲突及保留按键。命令面板支持筛选、上下键、回车。插入操作保留打开面板前的光标位置；阅读和源码模式限制不适用操作。
- Word 模板直接生成 OOXML 页面、字体和段落设置、标题编号、SEQ 图/公式编号、页眉与 PAGE 页码。脚注仍为原生 Word 脚注，公式继续使用 OMML。
- 对列表、引用和脚注按语法树递归转换，修正编辑器默认转换对多段结构的压平。未改动的源码片段保持原样；只重写有编辑的结构。复杂提示框及不支持结构保持原文块。
- 任务从语法树中的真实复选列表提取，记录精确字符位置；回写仅替换复选框的状态字符。先核对完整原文，避免行号失效后更新别处。
- 稳定定位写入公开 Markdown 注释，实时引用保持来源链接，不复制为静态正文。来源保存/窗口重新聚焦刷新预览；预览使用受限的 React 结构，不执行来源 HTML；引用不递归展开。文件改名复用原有链接事务。Word 导出时读取引用的最新保存内容，缺失时取消而不是省略。

验证通过：前端 96 项（含公开合成样本），Rust 33 项，真实桌面 59 项；类型检查、Clippy 和正式构建通过。桌面会话错误及 CSP 违规均为 0，两份输入样本哈希保持不变。实际验证包括批量替换、自定义快捷键保存、任务精确回写、脚注重开、来源标题改名后的实时引用与跳转、Word 原生保存对话框导出及模板设置。

报告：`artifacts/desktop-qa-YKc0BG/report.json`；前端、Rust、Clippy 和构建日志位于 `artifacts/*-4.4.log`。4.4.0 程序位于 `release/portable-note.exe`，4.3.0 保留在 `release/previous/portable-note-4.3.0.exe`。文件校验及测试汇总见 `artifacts/release-4.4.0.json`。

# 4.3.0 使用体验与整理优化

日期：2026-11-02。

## 范围

完成界面编辑、启动和大库性能、批量整理与集合、快速记录与每日笔记、附件管理五项。未加入定期备份和程序更新功能，也未扩展 PDF 精读。

## 实现与兼容

- 主题支持浅色、深色和跟随系统，编辑器、设置、集合、附件及快速记录使用一致主题；打印保持白纸黑字。
- 章节折叠通过独立控件和屏幕样式实现，不修改编辑器管理的正文 DOM，不改变 Markdown。查找或大纲跳转可展开目标章节，打印完整正文。
- 纯文本 TSV 粘贴生成表格，处理空格、空单元格、CRLF、引号、多行单元格；HTML 表格继续沿用编辑器格式粘贴，代码和公式编辑区不接管此行为。
- 第二个编辑器在实际使用右栏时创建。文件树只渲染可见行和少量预留行，支持键盘翻页和首尾导航。命中文件夹名称后保留其子笔记。链接预览短时间复用索引。
- 多选批量修改和标签重命名/合并共用事务写入：先核对全部原文、逐文件备份，并保留中断恢复日志。外部冲突取消整批写入。表格属性可直接编辑，支持排序、分组及将集合固定到侧边栏。
- 快速记录使用独立小窗口，主界面入口和 Ctrl+Shift+N 均可打开；Windows 注册 Ctrl+Alt+N，快捷键被占用时保留应用内入口。记录到收件箱或追加今日笔记，保存时间、来源。小窗口不创建块编辑器；草稿保留在本机，切库后先核对目标位置。
- 附件以 256 KB 分块传输，未完成的数据放在临时区，取消时丢弃未完成文件。新附件通过 SHA-256 内容地址去重，不改已有笔记的附件链接；多文件可选择或拖入，已完成部分在取消后保留。
- 附件管理后台计算校验值，显示重复内容、当前笔记引用和缺失路径；选择替代文件后统一预览并应用路径映射，更新原文前仍检查外部变更。
- 笔记附件包使用后台流式 ZIP 压缩，进度可见并可取消，完成后才替换目标 ZIP。旧目标在失败或取消时保留。

## 验证

前端公开样本 86 项、Rust 33 项，类型与静态检查通过。桌面验收在原 45 项基础上增加 8 项工作流，包含主题、折叠/粘贴、批量整理、附件去重与取消、缺失修复、打包取消、独立快速记录窗口和千文件树。性能记录位于本轮验收的 `performance-4.3.json`；启动、输入驱动往返、可见行数及近似 JS 堆数据用于后续比较，不作硬性速度承诺。

最终程序哈希与验收路径保存在忽略的 `artifacts/release-4.3.0.json`。便携程序为 `release/portable-note.exe`，上个 4.2.0 程序保留在 `release/previous`，不会移动或覆盖笔记数据。

# 4.2.0 优化记录

日期：2026-11-02。

## 本轮范围

完成快速搜索与导航、自动保存与笔记库管理、属性与智能集合、双向链接、模板与内容片段五项改进。PDF 精读、OCR 和批注不在本轮范围，原 PDF 预览与打印保留。

## 设计与兼容

- 后端索引按文件时间和大小更新，保留原文与小写搜索缓存；前端只接收、解析变化的笔记。缓存可重建，不替代 Markdown 原始数据。搜索替换分页也复用缓存。
- 属性使用 YAML 文档解析器保留自定义字段、注释和正文；格式不合法时拒绝属性编辑，原文件不改写。未编辑笔记维持原文字节。属性以独立属性块显示，双向链接以行内链接显示。
- 智能集合保存筛选条件，笔记不复制；支持目录、标签、类型、状态、修改日期、列表和表格。最近访问和集合随笔记库保存。
- 双方括号及标准 Markdown 链接共用目标解析，支持标题定位、反向引用和悬停预览。改名维护会避开代码、HTML、属性和公式中的字面文本，保留别名。重名有歧义时要求选择完整路径。
- 移动/改名和引用更新使用可恢复日志，校验原文、逐笔记备份；中断恢复前再次检查是否存在额外修改。历史路径关联继续保留。
- 自动保存默认空闲 5 秒，可调为 15/30/60 秒或关闭；中文输入组合、弹窗、其他保存操作期间延后。恢复草稿继续独立写入。外部修改每 3 秒及窗口激活检查，无本地修改时刷新，有修改时保留并比较，原文件移走时可另存。
- 每个笔记库有进程占用锁；打开其他库时先保存两栏与原工作区，再切换并重新加载。外部库位置只记在程序旁本机配置中。
- 整库备份复制笔记、附件、草稿、历史、模板、回收站和设置，跳过占用锁。文件夹备份携带 SHA-256 清单，所有文件校验后才发布；恢复生成独立目录，不覆盖已有笔记库。目录链接、清单异常、路径越界和文件损坏会拒绝处理。
- 模板分整页和片段，内置论文、实验、会议、周报、检查清单，可保存选择的内容块与整页，支持编辑后另存。变量仅替换明确支持的三个名称，保留公式花括号；相对笔记链接在复用时重新定位，附件仍以库根目录为基准。

## 验证

- 前端公开样本回归 77 项、Rust 27 项，类型与 Rust 静态检查通过。
- 桌面验收涵盖原有 33 项和本轮新增 12 项：属性、快速搜索与集合、反向引用、链接插入与导航、双方括号联想、模板片段、改名引用维护、自动保存、外部修改、缓存复用、整库校验恢复、笔记库切换隔离。
- 生产构建采用 Tauri CLI，程序使用嵌入的前端。编辑器和部分图表分块仍有体积警告，未隐藏警告。

本机验收目录和程序哈希记录在忽略的 `artifacts/release-4.2.0.json`；便携程序整理到 `release/portable-note.exe`。数据和测试生成内容不纳入源码发布。

# 4.1.0 优化记录

日期：2026-11-01。

## 已完成

1. **Callout 内容完整性**：正文绑定 BlockNote 的内容区域，标题可编辑，阅读模式下禁止修改。采用 `> [!INFO/WARNING/ERROR/TIP]` 保存，保留正文、行内格式和公式。无法表示成行内内容的复杂提示框继续保留原文，避免丢失嵌套内容。已丢失的历史正文无法根据界面文字自动补回。
2. **附件便携性**：新写入的附件链接使用相对笔记库的路径；显示时映射当前目录，兼容旧的绝对链接。新增链接检查、缺失提示、选择迁移和包含附件的 ZIP 导出。迁移只改真实 Markdown 链接目标，不改代码中的相似字符串。
3. **恢复流程**：空闲后自动写入草稿，按会话隔离，保留尚未恢复的旧内容；启动时提供恢复选择。新增历史版本列表、差异预览和恢复，改名或移动后仍能追踪历史。外部冲突可以采用磁盘版本并保留恢复草稿，或将编辑内容另存为副本。
4. **搜索闭环**：全局搜索分页展示，准确提示还有更多结果；点击结果定位对应内容并高亮。替换先展示差异和数量，默认排除代码、HTML、公式和链接地址，也可手动包含。保存时再次检查磁盘原文。
5. **双栏一致性**：两栏共用编辑器、源码模式和插入菜单；搜索、撤销/重做、字数、大纲和导出跟随活动栏。禁止同一笔记在两栏重复编辑。
6. **阅读与界面**：正文最大宽度、字号、行距可调整；统一导航图标和工具栏；小窗口收起次要导出按钮，大纲改为覆盖面板。新增完整 Markdown 源码编辑。收藏、标签页、滚动位置、布局和阅读设置保存在笔记库中。文件树支持方向键和 Enter。
7. **结构与性能**：拆出文件树、工具栏、编辑器、搜索、恢复、历史和设置组件，以及导出服务、草稿保护、附件路径、差异和替换工具；后端拆出笔记库与分页搜索模块。脏状态按变更块更新，文件树避免跟随正文输入重复渲染。附件预览按可视区域和展开状态加载，最多同时解析两份，文本预览限制读取量。搜索高亮不修改编辑器管理的 DOM。打印前准备附件预览。

## 兼容边界

- 未修改的旧 Markdown 继续保留原文；附件迁移需要在界面中明确选择。
- 相对附件路径以库根目录为基准；导出 ZIP 会把笔记放到根目录，以便独立使用。
- Word 保持原生 Office Math；不支持的复杂公式仍会明确中止导出。Word 附件为链接，需要一起携带附件时使用 ZIP。
- PDF 继续使用系统打印。自动验收验证 WebView 的打印输出，不包含所有物理打印机驱动的系统界面。
- 文本附件最多预览约 64 KB，Word 大附件可直接用系统程序打开；原文件不截断。
- 编辑器和 Mermaid 仍存在较大的构建分块，构建警告保留，没有用提高阈值隐藏。

## 验证

- 常规前端回归 63 项；带两份公开合成样本共 65 项，均通过，涵盖全部自定义块、Callout 四种类型、相对附件、源码保真、替换保护、万块文档增量脏状态、预览并发和 ZIP 内容。
- Rust 回归 22 项通过；类型检查和 Rust 静态检查通过。
